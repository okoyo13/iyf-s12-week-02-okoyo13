Exercise 2 · Debug the Layout

Both boxes have width: 300px and padding: 20px. One is broken, one is fixed.

❌ Broken

Total width = 340px
width: 300px + padding 20px each side = 340px (content-box)

Because box-sizing defaults to content-box, padding is added to width.

✓ Fixed

Total width = 300px
box-sizing: border-box; padding included within 300px

Add box-sizing: border-box to include padding and border in the width.

Fix: Add box-sizing: border-box; to .broken-box. With border-box, the 20px padding is subtracted from the 300px width, leaving 260px for content. Total visible width remains 300px (border is none in this exercise).
